## Reddit preflight checklist

Before every manual comment or native post:

1. Check the current rules for each community, including self-promotion, link, flair, account-age, and designated-promotion-thread rules. If uncertain, do not post or ask moderators through the permitted channel.
2. Make the useful explanation complete on Reddit; an optional link must directly answer the question and be permitted by that community.
3. Disclose affiliation when Nudge is relevant: “I’m the founder of Nudge, an AI Front Desk for WhatsApp.” Do not conceal the commercial relationship.
4. Write a community-specific contribution; no copy-pasted cross-posts, no link-dumping, and no subreddit target list.
5. Do not automate Reddit posting. No unsolicited DMs, no vote manipulation, no alternate-account amplification, and no mass outreach.
6. Check that the advice remains compliant: official Meta Cloud API only; marketing to opted-in recipients only; STOP wins; outside the 24-hour service window, use approved templates rather than free-form business-initiated messages.

This manual posture follows Reddit's current guidance on [spam](https://support.reddithelp.com/hc/en-us/articles/360043504051-Spam), [disrupting communities](https://support.reddithelp.com/hc/en-us/articles/360043066412-Disrupting-Communities), and [not breaking the site](https://support.reddithelp.com/hc/en-us/articles/360043512931-Don-t-break-the-site). In particular, these sources warn against repetitive or unsolicited engagement, vote manipulation, and automation or data collection that degrades the service. Read them again before changing this operating rule.

## Privacy-safe UTM convention

For an allowed optional link, use only aggregate, non-identifying campaign values:

`?utm_source=reddit&utm_medium=founder_organic&utm_campaign=ai_front_desk_content&utm_content=topic_slug`

Use a generic topic slug, not a person or forum identifier: no usernames, post IDs, community names, or personal data. Never use UTMs to build Reddit-user profiles or to prompt outreach.
